# 自动 BOSS

独立模块 `bosshunt`，仅支持 DHXY。地图改为「选择地图」多选弹窗并立即保存，首次默认不选；全部取消后保持空选择，重新打开页面不会自动启动服务。

## 地图与顺序

地图清单不再写死：worker 读取客户端 `data_MapInfo` 表，把全量 `id:名称` 写进 status 的 `mapCatalog` 字段，服务端解析后落盘到 `module.bosshunt.settings` 的 `map_catalog_v1`，页面据此渲染弹窗。历史只读扫描曾导出 83 张地图（含大雁塔各层、帮派、玩家之家、比武场、封印地图等副本场景）。

内置兜底（首次运行、尚未导出时使用）：

| 顺序 | 地图 | 逻辑地图 ID |
| --- | --- | --- |
| 1 | 东海渔村 | 1010 |
| 2 | 地府 | 1002 |
| 3 | 北俱芦洲 | 1003 |
| 4 | 御马监 | 1016 |
| 5 | 宝象国 | 1018 |

早期内置 ID 来自 `.scratch/map-inventory2-20261013-result.txt`。逻辑地图 ID 不得替换成地图资源复用的内部 `mapId`。巡回按所选地图的逻辑 ID 升序执行；命令中的地图集合采用严格升序 CSV，集合的存储顺序不代表巡回顺序。

## 动作流程

扫描当前地图动态 NPC 的 `name` 或 `title`，以 ASCII 大小写无关方式匹配子串 `boss`。候选必须具有有效实例 ID、当前地图和整数坐标；发起动作前再次校验目标、角色、地图、停止请求与租约。

显式开始后先建立新的 SCAN 会话，再提交一次绑定该会话的 RUN。巡回只处理所选地图；没有候选、候选忙碌或本轮已处理完时继续下一地图。跨地图落点从运行时地图表读取，缺失时不构造坐标；跨图确认等待上限 8 秒，整圈设有 5 秒冷却。单选地图没有目标时原地等待刷新。

到达 BOSS 位置并取得确认后，先请求该 NPC 的真实对话按钮，从与当前目标匹配的响应中读取明确的挑战选项，再提交该按钮的实际 action。不会把星怪专用 `threats_star` 用于 BOSS。观战入口、缺失或歧义的挑战选项不作为开战授权。挑战后等待本角色的战斗确认，战斗结束继续巡回。

NPC 协议形状依据历史 `scene-entities-20261016/challenge-functions.json`；传送协议形状依据该目录的 `teleport-functions.json`。协议字段与本地实现不能证明当前服务器接受跨图或 BOSS 挑战。

## 隔离与停止

- 设置：`module.bosshunt.settings`，键 `selected_maps_v1`。
- 应用文件：`files/modules/bosshunt`；游戏缓存：`wpe-modules/bosshunt`。
- 原生 worker：`libbosshunt_worker.so`；Lua 状态键：`__codex_bosshunt_v1`。
- 命令仅接受 `sequence/mode/maps/map` 四字段，地图集合仅接受当前已加载地图目录中的 ID；首次无导出目录时使用上表五个默认 ID。
- 与找星、暗雷共享动作互斥，但各自占位、设置、命令、租约、日志与停止记录独立。
- 常规停止以当前序号确认、stopped/fatal 状态及 hooksRemoved/bindingCleared 清理证据作为完成依据；若 worker 明确报告停止请求后原游戏进程已结束且 sessionDetached，也可完成停止。单有 worker 退出不能证明游戏内清理完成。

## 验收边界

用户后续明确授权覆盖安装并仅检查界面与保存，已在 emulator-5554 完成。当时五张内置地图的全选、多选和全部取消均跨重新打开保留，找星设置不变；未启动 BOSS 服务或进行游戏请求。真实服务器上的跨地图到达、BOSS 按钮返回及完整战斗循环尚未验收。包与审查记录见 [BOSSHUNT_VALIDATION.md](BOSSHUNT_VALIDATION.md)。

## 本轮增量：直接传送

显式选择一张已加载地图后提交 `teleport` 命令，`maps` 必须恰好包含该目标，`map` 为同一目标 ID。它是一次性任务，不提交 NPC 对话或挑战；必须先停止当前任务并确认清理，启动后保留动作互斥占位直到停止确认。Java/Rust/Lua 均解析此模式；Lua 在停止、租约、角色、战斗、连接和队伍操作条件不满足时不发送。成功只按本次命令的目标地图确认，超时和发送失败保留各自原因。与找星共用的地图清单只含 ID 和名称，模块的选择与命令仍独立。离线验证不代表当前服务器或设备接受传送。
