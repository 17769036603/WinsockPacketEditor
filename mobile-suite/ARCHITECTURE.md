# APK 整合边界

战斗跳过页面的跳过与隐藏选项独立生效，以单一双布尔配置原子发布并按运行冻结。只隐藏时安装入战视觉入口、租约观察与透明切图诊断，不进入跳过业务或自动状态恢复；只跳过保留原流程。切图诊断区分发送调用、进入地图回包和本地地图变化，复用有界视觉日志及自有 Hook 清理，不发起业务请求。两项都关闭时在占位、Root 和连接游戏前阻止启动。旧缺省跳过为 true，新配置损坏则拒绝连接。见 [BATTLE_HIDE.md](BATTLE_HIDE.md)。

战斗跳过的可选隐藏画面功能复用本模块的入战 wrapper、worker、租约与停止生命周期。配置在每次启动时冻结并注入 Lua；显示逻辑不新增发送、收包拦截或战斗旗标修改。隐藏启用的会话须额外确认 `visibilityRestoreConfirmed=true` 才能认可正常清理回执。独立视觉日志与既有选敌日志分开，详见 [BATTLE_HIDE.md](BATTLE_HIDE.md)。

本副本保持原有模块、目录、配置、授权、动作互斥及停止恢复边界，新增内容只承担观察、显示、任务结果记录和交付验证。

- 模块界面继续在 UI 线程读取 Activity/服务连接字段；`UiStatusFiles` 在后台读取仅用于显示的文件缓存。动作前的真实门禁与恢复判据不使用显示缓存。
- 宿主以模块及目标为键保存不可变状态快照，丢弃旧目标的迟到结果，过期显示未知。侧栏根据显示值变化更新控件。
- 诊断格式化层仅接收允许的版本、构建、授权模式、架构、状态枚举和调度摘要；不直接序列化完整模块状态或原始日志。
- 调度结果按单次执行及逐目标记录，派发与模块确认分开。观察器仅根据本次关联证据确认本地结果，缺失关联或超过等待期限保持未确认；不自动重发游戏动作。
- 交付工具读取 APK 实际元数据及签名，与指定基准比较，再写入不覆盖既有目录的制品、哈希和来源清单。证书/版本预检不等于任务数据或运行效果兼容。
- 原生包体实验与正式构建隔离。实验工具的导出及压缩检查不能代替 Android 装载和真实模块验收，当前不改变生产 Frida 链接方式。

- 周期调度在本地日历上生成每小时整点/半点的实际触发时刻，提前量跨午夜计算；旧每日任务保持单独的时刻语义。任务修改、启用状态、逐次防重和逐目标执行记录由各自模型维护。
- 找星和 BOSS 的定时启动沿用各自保存的星级和地图集合。BOSS 停止记录与挂机请求独立维护；未确认清理时保留动作占位与重试入口，停止后的迟到扫描结果不能恢复挂机。

## 找星脚本卸载边界

找星的 Lua 停止状态只证明业务调度和绑定清理，不能证明游戏 GL 线程上的 Java 回调已经返回。找星 agent 使用 `FutureTask` 跟踪已投递的任务；停止时关闭后续 tick，等待旧任务完成，再执行一次清理任务。只有清理任务实际完成且未取消、未异常，才发送本次 `runId` 的 `drained` 回执。

原生 worker 同时核对本会话结果路径中的 Lua 停止及双清理标志，以及匹配 `runId` 的 agent 回执，之后才卸载脚本和分离会话。等待回执时对应用发布 `stopping`；超时不代替回执。原游戏进程已结束的分支独立处理，不将进程退出标记成 Lua 清理成功。该边界仅用于自动找星，其他模块的生命周期保持独立。
