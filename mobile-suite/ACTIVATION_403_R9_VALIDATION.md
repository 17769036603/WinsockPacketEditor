# 朋友版激活 403 排查与打包

日期：2026-10-17。

## 结论与边界

朋友截图显示 code 10 旧版在输入激活码后提示“激活码无效或已使用（403），现有授权保持不变”。旧客户端将任何激活 403 都显示成这个提示，因此截图无法区分网关拒绝和业务授权拒绝。

对正式 `/v1/activate` 发送不含真实激活码的 `{}` 请求，Python 默认 User-Agent 得到 `403 text/plain` 和 `error code: 1010`；Android Dalvik 标识和新版真实应用标识得到 `400 application/json` 的参数错误，证明这两类请求到达授权程序。400 是刻意使用空参数的预期结果，不代表完成激活。Cloudflare 官方文档将 1010 定义为客户端浏览器签名被拒绝：https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1010/ 。这支持存在网关拦截，但不能据此证明朋友那次请求也返回了 1010。

Sites 只读检查确认站点公开、当前线上版本为 4；授权表中未发现截图所示安装识别码对应的成功绑定。没有修改授权表、发码、续期、停用、解绑或部署服务端，没有使用截图中的激活码发送请求。

## 客户端修改

- 授权 HTTP 请求设置 `PiaomiaoHelper/<VERSION_NAME> (Android)`，不依赖系统默认请求标识。
- 在原有 8192 字节上限内读取错误响应，只按有限 JSON 字段区分业务错误，不展示或保存原始响应内容。
- 激活 403 分别提示服务访问拒绝或激活请求被拒绝，不再一律声称激活码无效/已用。
- 验证 403 只有精确 `LICENSE_EXPIRED` 执行到期处理并保留会话供续期；其他 403 保留原会话和仍未过期的短租约，不延长租约。已有租约耗尽后应用监督仍安全停止功能。验证 401 仍清除失效会话。
- 版本更新为 `versionCode=11`、`versionName=2026.10.17.1-friends`，包含 r8 战斗跳过重复停止和金蝉页面绑定修复。
