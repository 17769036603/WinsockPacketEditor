## 边界

本轮不更改游戏业务脚本、模块动作频率、授权租约、互斥和恢复规则，不生成新的正式签名密钥。当前安装 code 14 的免激活模式只通过本轮显式构建参数延续；普通构建继续默认保留授权门禁。

安装会终止或重启助手应用，真实功能验收可能改变正在运行的任务或发起游戏操作。候选完成后再确定设备、模块、时长和执行范围；未执行的设备测试不得标记通过。生产网站和历史交付物不随本轮本地构建自动更新。
