# 飘渺助手统一 APK

用户要求：最终名称“飘渺助手”；整合截图中自制助手，排除肉包。左侧各功能独立导航，右侧详情、参数和开启/停止；功能独立运行。

确认范围：战斗观察面板（原飘渺助手）、暗雷遇敌、角色速度保持、战斗循环、战斗快进、金蟾装备助手。

实现范围：新增 mobile-suite；原六模块不编辑，旧 APK 与用户配置不覆盖；不安装设备、不执行游戏动作。

验收：一个 launcher；六个功能的完整控制与 native worker 打包；文件、缓存、偏好和通知隔离；精确模块路径校验；导航不自动连接、不切换其他功能；停止保持原恢复/清理语义；assembleDebug、隔离回归、签名/ABI/包内容检查；CodeRabbit。

计划判断：实际 Decisions API 调用返回 LOW_CONFIDENCE、status=not_run；主代理按静态证据接手，不能将其作为通过。

实际设备 UI、Root 授权、并发清理和游戏结果均需另行验收。
